Zakat and tip (icon calc, theme slate).
You can change: "Cash and bank" (money, starts at 0), "Gold (grams)" (number, starts at 0), "Silver (grams)" (number, starts at 0), "Gold price per gram" (money, starts at 0), "Silver price per gram" (money, starts at 0), "Debts due now" (money, starts at 0).
Works out:
- wealth = cash + gold * gold_rate + silver * silver_rate - debts.
- nisab = 612.36 * silver_rate.
Remembers while you use it: bill (starts at 0), tip (starts at 10), people (starts at 1).
Shows:
- screen "Zakat":
  - an input for cash.
  - an input for gold.
  - an input for silver.
  - an input for gold_rate.
  - an input for silver_rate.
  - an input for debts.
  - text ["Zakat due (2.5%)" if wealth >= nisab, else "Below nisab: no zakat due"].
  - text [wealth * 0.025 if wealth >= nisab, else 0 rounded].
- screen "Tip":
  - an input for bill ("Bill").
  - text "Tip" [tip] "%".
  - a slider for tip from 0 to 30.
  - text "People" [people].
  - a slider for people from 1 to 20.
  - text "Tip" [bill * tip / 100 rounded].
  - text "Each pays" [bill * (1 + tip / 100) / people rounded].
