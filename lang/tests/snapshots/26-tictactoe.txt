Tic tac toe (icon board, theme ink).
Keeps:
- move: game (number), cell (number, 1 to 9), mark (one of X, O). Every entry also keeps when it was added.
You can change: "Game" (number, starts at 1).
Works out:
- n = number of move where game = cur.
- turn = "X" if n % 2 = 0, else "O".
- xw = how many of 123, 456, 789, 147, 258, 369, 159, 357 have number of move where game = cur and mark = "X" and (cell = floor(the item / 100) or cell = floor(the item / 10) % 10 or cell = the item % 10) = 3 > 0.
- ow = how many of 123, 456, 789, 147, 258, 369, 159, 357 have number of move where game = cur and mark = "O" and (cell = floor(the item / 100) or cell = floor(the item / 10) % 10 or cell = the item % 10) = 3 > 0.
Shows:
- if xw or ow:
  - text ["X" if xw, else "O"] "wins!".
- otherwise:
  - text ["Draw" if n = 9, else turn] ["" if n = 9, else "to play"].
- a grid of 3 columns:
  - for 1 to 9:
    - if number of move where game = cur and cell = c = 0 and not xw and not ow:
      - a box; tap adds a move (game = cur, cell = c, mark = turn):
    - otherwise:
      - text [latest mark of move where game = cur and cell = c].
- a button "New game"; tap sets cur to cur + 1.
