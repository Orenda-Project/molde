Habits (icon check, theme mint).
Keeps:
- habit: name (text). Every entry also keeps when it was added.
- check: habit (a habit). Every entry also keeps when it was added.
Works out:
- n = number of habit.
- done = number of check today.
Shows:
- a progress ring: done out of n ("done today").
- text ["All done today" if done = n and n > 0, else "Keep going"].
- text "Best streak" [highest of current day streak of its check over habit] "days".
- if n = 0:
  - text "Start with one small thing you can do on a busy day.".
- for habit:
  - a stack; tap opens h for editing; swipe removes h (with undo):
    - text [name of h].
    - text [current day streak of check of h] "days".
    - a tick box for check of h.
    - for each day in the last 7 days:
      - a stack; tap marks or unmarks check of h on that day:
        - text [dayname(the item)].
- a big number: number of check this week * 100 / (n * weekday(today)) rounded ("% this week").
- a big number: number of check in the last 30 days * 100 / (n * 30) rounded ("% last 30 days").
- text "Last 10 weeks".
- a grid of 7 columns:
  - for each day in the last 70 days:
- text "Each row is a week. Darker means more habits done.".
- a form to add a habit.
