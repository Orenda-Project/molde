To do (icon list, theme ink).
Keeps:
- task: title (text), due (date, optional), done (yes/no), tag (one of Home, Work, Other, starts at Home). Every entry also keeps when it was added.
Works out:
- late = number of task where done = no and due < today.
Shows:
- text [number of task where done = no] "open," [late] "late".
- for task where done = no sorted by due:
  - a row; tap opens t for editing; swipe removes t (with undo):
    - a tick box for done of t.
    - text [title of t].
    - text [tag of t] [due of t].
- a form to add a task.
- text "Done".
- a list of task where done = yes (tap to edit, swipe to remove).
Reminder "You have tasks due today" at 8:00 if number of task where done = no and due = today > 0.
