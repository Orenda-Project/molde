To do, in the ink colours.
Keeps:
- task: title: text; due: date, optional; done: yes or no; tag: one of Home, Work, Other, starts at Home. Every entry also keeps when it was added.
Works out:
- late is how many task entries where done is no and due is less than today.
Shows:
- text: how many task entries where done is no, "open,", late, "late".
- for each task where done is no sorted by due:
  - a group; a tap opens the task for editing; a swipe removes the task, with undo:
    - a tick box for the done of the task.
    - text: the title of the task.
    - text: the tag of the task, the due of the task.
- a form to add a task.
- text: "Done".
- a list of task where done is yes; tap one to edit it, swipe to remove it.
Reminder "You have tasks due today" at 8:00 every day, only if how many task entries where done is no and due is today is more than 0.
