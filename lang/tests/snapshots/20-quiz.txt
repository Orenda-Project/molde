Quiz, in the plum colours.
Keeps:
- item: question: text; a: text; b: text; c: text; right: one of A, B, C. Every entry also keeps when it was added.
- answer: item: a item; chose: one of A, B, C. Every entry also keeps when it was added.
Works out:
- score is how many of the answer have its chose is its item right.
Shows:
- text: score, "of", how many answer entries, "right".
- for each item:
  - if how many the item's answer entries is 0:
    - text: the question of the item.
    - a button the a of the item; a tap adds a answer with item set to the item, chose set to A.
    - a button the b of the item; a tap adds a answer with item set to the item, chose set to B.
    - a button the c of the item; a tap adds a answer with item set to the item, chose set to C.
- for each answer:
  - text: the item question of the answer.
  - text: "Right" when the chose of the answer is the item right of the answer, otherwise "Wrong".
- a form to add a item.
