Cricket (icon ball, theme ocean).
Keeps:
- ball: runs (number, 0 to 6, starts at 0), wide (yes/no), out (yes/no). Every entry also keeps when it was added.
You can change: "Overs" (number, starts at 20).
Works out:
- legal = number of ball today where wide = no.
- runs = total runs of ball today + number of ball today where wide = yes.
- wkts = number of ball today where out = yes.
Shows:
- text [runs] "/" [wkts].
- text "Overs" [floor(legal / 6) + legal % 6 / 10] "of" [overs] ". Run rate" [runs * 6 / legal rounded].
- for 0, 1, 2, 3, 4, 6:
  - a button [the item]; tap adds a ball (runs = the item).
- a button "Wide"; tap adds a ball (wide = yes).
- a button "Out"; tap adds a ball (out = yes).
- a button "Undo"; tap removes latest ball today (with undo).
- text "Last balls".
- for ball today sorted by at (highest first), first 6:
  - a drawing (circle, label).
