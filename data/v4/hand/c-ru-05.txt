darzi ke orders
---
app "Darzi" tag plum
table order customer text, suit text, due date = today, ready bool
each order where ready = no sort due as o empty "Koi order baqi nahi"
  row card gap 2 tap edit o swipe remove o
    toggle o.ready
    stack grow gap 0
      o.customer bold
      o.suit faint
    o.due faint color if(o.due < today, bad, muted)
form order, "Naya order"
