@rich domain=d4_frame_time_scenes topic=scene_frame_time_budget style=detailed
performance pass on my game: for each scene I write the frame time in ms I measured and the device. I set a frame budget (16.6 for 60 fps), scenes over it go red, I want a bar comparison of the scenes and the fps each one gives
needs: add a scene with frame time and device | set the frame budget | red for scenes over budget | bar comparison of scenes | fps per scene
---
app "Frame budget" bolt purple dark
table scene name text, ms num 0.1.. unit "ms" "Frame time", device pick Phone|Tablet|PC = Phone
setting budget num = 16.6 "Frame budget (ms)"
topbar scene, "Add scene"
statcard count(scene where ms > budget), "scenes over the frame budget", count(scene)
section "Frame time by scene", "milliseconds"
  bars scene sort ms desc, it.ms, it.name
each scene sort ms desc as s empty "No scenes measured yet. Profile the heaviest level first."
  row card gap 2 tap edit s swipe remove s fill if(s.ms > budget, bad, soft)
    stack grow gap 0
      s.name bold
      s.device faint
    round(1000 / s.ms) "fps" bold
