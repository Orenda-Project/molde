needs: add an order with name, flavour and dozens | open and done tabs | button to mark handed over | chart of dozens by flavour | total dozens still to bake
---
app "Cookie Orders" food green
table order name text, flavour pick Choc_chip|Oatmeal|Peanut|Sugar = Choc_chip, dozens num 1..20 = 1, done bool
state tab text = Open
topbar order, "Add order"
statcard sum(order.dozens where done = no), "dozens still to bake"
row gap 1
  each ["Open", "Done"]
    button it fill if(tab = it, accent, soft) grow tap set tab = it
each order where (tab = Open and done = no) or (tab = Done and done = yes) sort at as o empty "No orders in this tab."
  row card gap 2 tap edit o swipe remove o
    stack grow gap 0
      o.name bold
      o.dozens "dozen" o.flavour faint
    if o.done = no
      button "Handed over" fill accent tap set o.done = yes
section "Dozens by flavour"
  share order by flavour, sum(it.dozens), it.key
===
@rich domain=r9_handmade_stock topic=handmade_goods_stock style=multi_feature
I sell crochet bags, keychains and hair clips at fairs. Keep stock count and price for each item, buttons to take one off when I sell it, a red warning when only 2 are left and the total value of everything on the table
needs: add an item with name, stock and price | sell one button reduces stock | warns when 2 or fewer are left | total value of stock | add stock button
---
app "Craft Stock" gift teal
table piece name text, stock num 0..999 = 5, price money
let worth = sum(piece, it.stock * it.price)
topbar piece, "Add item"
row gap 2
  statcard worth, "on the table"
  statcard count(piece where stock <= 2), "need making"
each piece sort stock as p empty "No items yet. Add what you make."
  stack card gap 1 tap edit p swipe remove p
    row
      p.name bold grow
      p.price faint
    row gap 2
      p.stock "left" bold color if(p.stock <= 2, bad, ink) grow
      button "Sold 1" tap set p.stock = p.stock - 1
      button "+5" tap set p.stock = p.stock + 5
===
@rich domain=r9_candle_batches topic=candle_pouring_and_curing style=detailed
I pour soy candles and they need 14 days to cure before I sell. Log each batch with scent, wax grams and pour date, then show the date it is ready and how many days are left. tell me how many candles are ready to sell now
needs: log a batch with scent, wax grams, pour date and candle count | shows ready date | shows days left to cure | counts candles ready to sell | settable cure days
---
app "Candle Batches" fire blue
table pour scent text, wax num 100..20000 unit "g", day date = today, jars num 1..200 = 6
setting cure num = 14 "Cure days"
let ready(b pour) = b.day + cure
let fit = sum(pour, if(ready(it) <= today, it.jars, 0))
let curing = sum(pour, if(ready(it) > today, it.jars, 0))
topbar pour, "Log pour"
row gap 2
  statcard fit, "candles ready to sell"
  statcard curing, "still curing"
each pour sort day desc as b empty "No pours yet. Log the first batch."
  row card gap 2 tap edit b swipe remove b
    stack grow gap 0
      b.scent bold
      b.jars "jars," b.wax "g wax" faint
    if ready(b) <= today
      "Ready" bold color good
    else
      stack gap 0 align end
        ready(b) - today "days" bold
        "ready" ready(b) tiny faint
