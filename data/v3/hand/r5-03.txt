needs: eight round circles | button to finish a round | 20 second timer | save workout when round 8 is done | workouts this week
---
app "Tabata" bolt orange dark
table hiit n num 8..8
state r num = 0
draw 100, 14 alt "rounds done"
  each 1..8
    circle index * 12 + 6, 7, 5 fill if(it <= r, accent, soft)
timer 20s, "Work", set r = min(r + 1, 8)
button "Reset" tap set r = 0
when r >= 8 add hiit n = 8 then notify "Tabata finished"
row gap 2
  statcard r, "of 8 rounds done", 8
  statcard count(hiit week), "workouts this week"
