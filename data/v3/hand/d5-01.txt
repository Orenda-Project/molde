needs: log a backup with system, kind, size and verified tick | last run per kind | overdue per kind | verified count
---
app "Backups" box green
table bk sys text "System", kind pick Daily|Weekly|Monthly = Daily, gb num 0.. unit "GB", ok bool "Restore verified"
let dd = due(bk where kind = Daily, 1)
let wd = due(bk where kind = Weekly, 7)
let md = due(bk where kind = Monthly, 31)
topbar bk, "Log backup"
row gap 2
  stack card gap 0 grow
    text "Daily" faint
    text if(dd, "Overdue", "On time") bold color if(dd, bad, good)
    text plural(since(bk where kind = Daily), "day") "ago" faint
  stack card gap 0 grow
    text "Weekly" faint
    text if(wd, "Overdue", "On time") bold color if(wd, bad, good)
    text plural(since(bk where kind = Weekly), "day") "ago" faint
  stack card gap 0 grow
    text "Monthly" faint
    text if(md, "Overdue", "On time") bold color if(md, bad, good)
    text plural(since(bk where kind = Monthly), "day") "ago" faint
statcard count(bk where ok = yes), "restores verified of" count(bk), count(bk)
list bk by day, "No backups logged. Log tonight's run."
===
@rich domain=d5_severity_calc topic=incident_severity_calculator style=custom_ui
quick severity calculator for incidents: pick how many users are hit (few, some, most, all), tick whether the service is fully down, whether data is lost, whether there is a workaround, and show SEV1 to SEV4. let me save the result with a title to a log
needs: pick users affected | ticks for down, data loss and workaround | computed severity SEV1 to SEV4 | save result with a title to a log
---
app "Severity" bolt blue
table inc title text, sev text
state users pick Few|Some|Most|All = Some
state down bool
state data bool
state work bool
state ttl text = ""
let u = if(users = All, 3, if(users = Most, 2, if(users = Some, 1, 0)))
let score = u + if(down, 2, 0) + if(data, 3, 0) - if(work, 1, 0)
let sev = if(score >= 6, "SEV1", if(score >= 4, "SEV2", if(score >= 2, "SEV3", "SEV4")))
stack card gap 2 align center
  text "Severity" faint
  text sev huge color if(score >= 4, bad, if(score >= 2, warn, good))
  text "score" score faint
text "Users affected" head
choice users
row gap 2
  toggle down
  text "Fully down"
row gap 2
  toggle data
  text "Data lost"
row gap 2
  toggle work
  text "Workaround exists"
field ttl "Incident title"
button "Save to log" fill accent tap add inc title = ttl, sev = sev then set ttl = ""
each inc as i empty "No incidents saved yet."
  row card gap 2 tap edit i swipe remove i
    text i.title grow
    text i.sev bold
===
@rich domain=d5_story_velocity topic=story_point_velocity_chart style=detailed
velocity chart for my squad. every sprint I enter the name, points planned and points done. show a bar chart of points done per sprint, the average velocity, and what percent of planned points we finish overall
needs: add a sprint with planned and done points | bar chart of done points per sprint | average velocity | percent of planned points finished
---
app "Velocity" chart teal
table sprint name text, planned num 0.., done num 0..
topbar sprint, "Add sprint"
row gap 2
  statcard round(avg(sprint.done)), "average velocity"
  statcard round(sum(sprint.done) * 100 / max(sum(sprint.planned), 1)), "percent of planned done"

  section "Points done per sprint"
    bars sprint, it.done, it.name
else
  text "No sprints yet. Add the last one you closed." faint
