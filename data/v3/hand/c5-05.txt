@rich domain=c5_gas_meter_split topic=shared_gas_bill_floors style=detailed
two families share one gas connection but each floor has its own meter. i type last and current readings for both floors and the whole bill, and it should split the bill by units used and show what each floor pays
needs: previous and current meter readings for each floor | total bill | units used per floor | amount each floor pays
---
app "Gas Bill Split" fire ocean dark
state p1 num = 0
state c1 num = 0
state p2 num = 0
state c2 num = 0
state bill money = 0
let u1 = max(0, c1 - p1)
let u2 = max(0, c2 - p2)
let tot = u1 + u2
section "Ground floor"
  field p1 "Last reading"
  field c1 "Current reading"
section "First floor"
  field p2 "Last reading"
  field c2 "Current reading"
field bill "Total bill"
if tot = 0
  "Enter both readings to split the bill." faint
else
  row gap 2
    statcard round(bill * u1 / tot), "ground floor pays"
    statcard round(bill * u2 / tot), "first floor pays"
  "Units used:" u1 "and" u2 faint
===

  "Less than 25 years. Spend less or save more." bold color bad

  "That should last a long retirement." bold color good

@rich domain=c5_commute_cost topic=commute_cost_and_time style=short
commute cost
needs: distance one way | days per week | choice of car bike or bus | monthly cost | hours lost per month
---
app "Commute Cost" bus blue
state km num = 12
state days num = 5
state mode pick Bike|Car|Bus = Bike
let perkm = if(mode = Bike, 6, if(mode = Car, 22, 8))
let speed = if(mode = Bike, 30, if(mode = Car, 25, 18))
let trips = km * 2 * days * 4.3
choice mode
field km "Distance one way (km)"
field days "Days a week"
slider days 1..7
statcard round(trips * perkm), "a month"
"Time on the road" round(trips / speed * 10) / 10 "hours a month" bold
"Estimated at" perkm "per km and" speed "km/h." faint
