@rich domain=c3_lifting_total topic=powerlifting_total_strength style=multi_feature
powerlifting total: squat, bench and deadlift in kg plus my bodyweight. show the total, total divided by bodyweight and say if i am beginner, intermediate or advanced. let me save the day's total to see the progress
needs: squat bench deadlift and bodyweight inputs | total | ratio to bodyweight | level label | save total and see progress
---
app "Lifting Total" dumbbell ink dark
table meet total num
state sq num = 140
state bn num = 100
state dl num = 170
state bw num = 80
let total = sq + bn + dl
let ratio = if(bw > 0, total / bw, 0)
field sq "Squat (kg)"
field bn "Bench (kg)"
field dl "Deadlift (kg)"
field bw "Bodyweight (kg)"
statcard total, "kg total, x" round(ratio * 100) / 100 "bodyweight. Level:" if(ratio < 3, "beginner", if(ratio < 5, "intermediate", "advanced")), 0
button "Save today's total" fill accent tap add meet total = total
if count(meet) > 1
  section "Progress"
    trend meet, it.total
===

@rich domain=c3_triathlon_total topic=triathlon_finish_time style=detailed
triathlon plan: swim 28 min, bike 74 min, run 49 min, transitions 3 and 2 min. show the total finish time, what percent of the race each part takes and the clock time i finish if the start gun is at 7:30
needs: minutes for swim bike run and two transitions | total finish time | percent of each part | finish clock time from start time
---
app "Triathlon" bike teal
setting start time = 7:30 "Start time"
state swim num = 28
state bike num = 74
state run num = 49
state t1 num = 3
state t2 num = 2
let tot = swim + bike + run + t1 + t2
field start
row gap 1
  field swim "Swim min"
  field bike "Bike min"
  field run "Run min"
row gap 1
  field t1 "T1 min"
  field t2 "T2 min"
statcard tot, "minutes in total. Finish at" start + tot * 1m, 0
section "Share of the race"
  each 0..2 as k
    stack gap 0
      row
        if(k = 0, "Swim", if(k = 1, "Bike", "Run")) grow
        round(if(k = 0, swim, if(k = 1, bike, run)) / max(tot, 1) * 100) "%" bold
      draw 100, 3
        rect 0, 0, 100, 3 fill soft radius 1
        rect 0, 0, 100 * if(k = 0, swim, if(k = 1, bike, run)) / max(tot, 1), 3 fill accent radius 1
