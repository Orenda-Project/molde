needs: type who is booking | grid of days by evening hours | tap a free cell to book it | booked cell shows the name | remove a booking by tapping it
---
app "Court Slots" game teal
table booking day pick Mon|Tue|Wed|Thu|Fri|Sat|Sun, hour num 18..21, who text
state me text = ""
"Booking as" head
field me "Your name"
each options booking.day as d
  row gap 1
    d bold width 40
    each 18..21 as h
      if count(booking where day = d and hour = h) > 0
        box grow radius 6 pad 1 fill accent tap remove last(booking where day = d and hour = h)
          last(booking.who where day = d and hour = h) small color white
      else
        box grow radius 6 pad 1 fill soft tap add booking day = d, hour = h, who = me
          h "h" tiny
===
@rich domain=r8_running_club topic=running_club_leaderboard style=multi_feature
Sunday running club has 12 people. Add the runners, tap a button to add their km after a run, show a leaderboard for this month, and how far the club ran together toward the monthly target
needs: add a runner | one tap buttons to add km for a runner | monthly leaderboard | club total against monthly target | per runner km this month
---
app "Run Club" run orange
table runner name text
table run runner ref runner, km num 0.5..60 = 5
setting target num = 300 "Club km target"
topbar "Runners", runner, "Add runner"
goal sum(run.km month), target, "club km this month", "km"
section "Leaderboard", monthname(today)
  share runner sort sum(it.run.km month) desc top 5, sum(it.run.km month), it.name
each runner sort name as r empty "No runners yet. Add the first member."
  row card gap 2 tap edit r swipe remove r
    r.name bold grow
    sum(r.run.km month) "km" faint
    button "+5 km" tap add run runner = r, km = 5
    button "+10 km" tap add run runner = r, km = 10
===
@rich domain=r8_kit_lending topic=club_kit_lending style=detailed
our hockey club lends out sticks, balls and bibs. I add each kit item with how many we own, write who took it, and mark when it is returned. need to see how many of each are still in the cupboard and who has not returned theirs
needs: add a kit item with quantity owned | record who borrowed a kit item | mark a loan as returned | how many of each item are left in the cupboard | list of loans not yet returned
---
app "Kit Cupboard" box ink
table kit name text, qty num 1..500
table loan kit ref kit, player text, returned bool
state who text = ""
topbar "Kit", kit, "Add kit"
field who "Who is borrowing"
statcard count(loan where returned = no), "items out right now"
each kit sort name as k empty "No kit yet. Add what the club owns."
  row card gap 2 tap edit k swipe remove k
    k.name bold grow
    k.qty - count(k.loan where returned = no) "left of" k.qty faint
    button "Lend" tap add loan kit = k, player = who
section "Not returned yet"
  each loan where returned = no as l empty "Everything is back in the cupboard."
    row gap 2
      toggle l.returned
      l.kit.name grow
      l.player faint
