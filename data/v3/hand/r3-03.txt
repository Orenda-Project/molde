needs: log a repair with machine, problem and bill | tick when fixed | repair money this year | machine that cost the most | count of unfixed repairs
---
app "Pump repairs" tool slate
table repair machine pick North_well|Canal_well|Tractor|Thresher|Generator = North_well, problem text, bill money = 0, fixed bool, day date = today
topbar "Pump repairs", repair, "Log repair"
row gap 2
  statcard sum(repair.bill year), "spent on repairs this year"
  statcard count(repair where fixed = no), "repairs not fixed yet"
section "Cost by machine", "this year"
  share repair year by machine, sum(it.bill), it.key
each repair sort day desc top 10 as r empty "No repairs logged. Add one when something breaks."
  row card gap 2 fill if(r.fixed, soft, warn) tap edit r swipe remove r
    stack grow gap 0
      text r.machine bold
      text r.problem faint
    text r.bill bold
    toggle r.fixed

  daybars last 7 days, count(watered on it)
