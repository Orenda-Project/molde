@create style=custom_ui domain=a3_chess_clock
chess clock with two big halves, each player has 10 minutes, tapping your half stops your clock and starts the other, shows who is low on time
---
app "Chess clock" clock ink
state t1 dur = 600s
state t2 dur = 600s
state turn num = 0
every 1s if turn = 1 set t1 = t1 - 1s
every 1s if turn = 2 set t2 = t2 - 1s
grid 1 gap 2
  stack card align center pad 4 fill if(turn = 1, accent, soft) tap set turn = 2
    "Player 1" faint
    text t1 big color if(t1 < 60s, bad, ink)
  stack card align center pad 4 fill if(turn = 2, accent, soft) tap set turn = 1
    "Player 2" faint
    text t2 big color if(t2 < 60s, bad, ink)
button "Pause" tap set turn = 0
button "Reset" tap set turn = 0 then set t1 = 600s then set t2 = 600s
===

@create style=detailed domain=a3_overtime
Overtime pay calculator for my job. I log hours each day, anything above 8 hours counts at 1.5 times the hourly rate, and I see the total for the month.
---
app "Overtime" clock slate
setting rate money = 400 "Hourly rate"
table shift hrs num 0..16 = 8
let pay = sumof(shift month, min(it.hrs, 8) * rate + max(it.hrs - 8, 0) * rate * 1.5)

"Hours" sum(shift.hrs month) faint
"Overtime hours" sumof(shift month, max(it.hrs - 8, 0)) faint
form shift, "Log shift"
log shift
===

@create style=detailed domain=a3_score_spades

---

  stack grow card align center
    "Us" bold
    text us big
  stack grow card align center
    "Them" bold
    text them big
form hand, "Add hand"
log hand
===
