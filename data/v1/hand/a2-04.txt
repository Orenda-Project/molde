@create style=multi_feature domain=a2_task_board
task list with a status I can change between todo, doing, blocked and done, an optional due date, and chips on top to filter by status
---
app "Tasks" list ink
table task title text, status pick Todo|Doing|Blocked|Done = Todo, due date?
state show pick All|Todo|Doing|Blocked|Done = All
choice show
each task where show = All or status = show sort due as t
  stack card gap 1 tap edit t swipe remove t
    row gap 1
      t.title bold grow
      t.due faint color if(t.due < today, bad, muted)
    choice t.status
count(task where status != Done) "open tasks" faint
form task

@create style=custom_ui domain=a2_work_timer
a work timer with a start button and a stop button, I write what I am working on, and when I stop it saves the minutes
---
app "Work timer" clock ink
table entry task text, mins num 1..
state what text = ""
state going bool = no
state began when = now
field what "Working on"
if going
  "Working on" what head
  button "Stop" tap add entry task = what, mins = max(round((now - began) / 1m), 1) then set going = no
else
  button "Start" tap set began = now then set going = yes
"Today" sum(entry.mins today) "min" big
daybars last 7 days, sum(entry.mins on it)
log entry
===
