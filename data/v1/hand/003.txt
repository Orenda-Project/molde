@create style=detailed domain=m_barber_queue
Barber shop queue: I write the customer name and the service, tick when done, and see how many are waiting and how much I earned today.
---
app "Barber" user slate
table cut name text, service pick Haircut|Shave|Beard|Both = Haircut, price money, done bool
count(cut where done = no) "waiting" head
each cut where done = no sort at as c
  row card gap 2 tap edit c swipe remove c
    toggle c.done
    stack grow
      c.name bold
      c.service faint
    c.price bold
"Earned today" sum(cut.price today where done = yes) big
form cut, "Add customer"
===

@create style=custom_ui domain=m_thermo_steps

---

setting goal num = 50000 "Weekly target"
let p = clamp(sum(walk.steps week) / goal, 0, 1)

  rect 0, 0, 100, 30 radius 6 fill soft
  rect 0, 0, 100 * p, 30 radius 6 fill good

@create style=multi_feature domain=m_reading_screens
reading app with two tabs, one for what I'm reading now with pages done and total, one for finished books
---
app "Reading" book plum
table book title text, total num 1..3000, done num 0..3000 = 0, finished bool
screen current "Reading" book
  each book where finished = no as b
    stack card gap 1 tap edit b swipe remove b
      b.title bold
      goal b.done, b.total, "pages"
      button "+10 pages" tap set b.done = b.done + 10
      toggle b.finished
  form book
screen fin "Finished" check
  count(book where finished = yes) "books finished" head
  list book where finished = yes
