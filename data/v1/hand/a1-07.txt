@create style=multi_feature domain=a1_plant_due
plants with how often to water, show on top the ones that are due today, a water button for each, and a friendly message when nothing is due
---
app "Plant Due" plant mint
table plant name text, every num 1..60 = 4 unit "days"
table watered plant ref plant
"Due today" head
if countof(plant, due(it.watered, it.every)) = 0
  "Nothing needs water today" faint
each plant sort name as p
  if due(p.watered, p.every)
    row card
      text p.name bold grow
      button "Watered" tap add watered plant = p
"All plants" head
each plant sort name as p empty "Add your first plant below"
  row tap edit p swipe remove p
    text p.name grow
    "every" plural(p.every, "day") faint
form plant, "Add plant"
===
@create style=detailed domain=a1_pet_shots
Yearly shots for my pets. I add each pet, tap when it gets its vaccine, and the app shows which pets are overdue after one year.
---
app "Pet Shots" paw ocean
table pet name text, kind pick Dog|Cat|Rabbit|Bird = Dog
table shot pet ref pet
each pet sort name as p empty "No pets added yet"
  row card gap 1
    stack grow
      text p.name bold
      if due(p.shot, 365)
        "Vaccine due" color bad
      else
        "Last shot" last(p.shot.at) faint
    button "Had shot" tap add shot pet = p
form pet, "Add pet"
