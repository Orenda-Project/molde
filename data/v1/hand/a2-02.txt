@create style=detailed domain=a2_envelopes
I budget with envelopes. Each envelope has a name and a monthly limit, and when I spend something I pick the envelope. I want to see how full each one is this month.
---
app "Envelopes" wallet mint
table cat name text, limit money
table spend cat ref cat, amount money, note text?
state m date = today
monthnav m
each cat sort name as c
  let used = sum(c.spend.amount month of m)
  stack card gap 1
    row
      c.name bold grow
      text used "of" c.limit faint
    draw 100, 4
      rect 0, 0, 100, 4 fill soft radius 2
      rect 0, 0, 100 * clamp(used / c.limit, 0, 1), 4 fill if(used > c.limit, bad, accent) radius 2
form cat, "New envelope"
form spend, "Add spending"
===
