@create style=detailed domain=b5_library_lend
we run a tiny neighbourhood library out of a cupboard. need to know which books are out, who has them, and which are late. members borrow, bring back later
---
app "Cupboard Library" book mint
table book title text, author text?
table member name text
table loan book ref book, member ref member, due date, returned bool
let overdue = count(loan where returned = no and due < today)
overdue "overdue" big color if(overdue > 0, bad, good)
each book sort title as b
  let out = count(b.loan where returned = no)
  row card tap edit b
    b.title bold grow
    if(out > 0, "Out", "In shelf") color if(out > 0, warn, good)
form loan, "Lend a book"
form book, "Add book"
form member, "Add member"
===
