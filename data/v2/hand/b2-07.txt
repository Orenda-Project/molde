@create style=detailed domain=b2_pharmacy_batches
I run a small pharmacy. Medicines come in batches with different expiry dates. Show me for each medicine the quantity in stock, the batch that expires first, and a red flag for any batch past its date.
---
app "Pharmacy" pill ocean
table medicine name text, reorder num 0.. = 10
table batch medicine ref medicine, qty num 0.., expiry date
table sold medicine ref medicine, qty num 1..500
"Expired batches" count(batch where expiry < today) big color if(count(batch where expiry < today) > 0, bad, good)
each medicine sort name as m
  row card tap edit m
    m.name bold grow
    text sum(m.batch.qty) - sum(m.sold.qty) bold color if(sum(m.batch.qty) - sum(m.sold.qty) <= m.reorder, warn, ink)
    "first expiry" first(m.batch.expiry) faint
form medicine, "Add medicine"
form batch, "Receive batch"
form sold, "Record sale"
===

@create style=detailed domain=b2_target_grades
For each subject I set the percentage I am aiming for. I enter every test mark out of its total. Show my average per subject against the target, and highlight subjects where I'm behind.
---
app "Grade targets" target ocean
table subject name text, aim num 30..100 = 80 "Target %"
table test subject ref subject, got num 0..200, out_of num 1..200 = 100
each subject sort name as s
  let pct = round(100 * sum(s.test.got) / max(sum(s.test.out_of), 1))
  stack card gap 1 tap edit s
    row
      s.name bold grow
      text pct "%" big color if(pct < s.aim, warn, good)
    "Target" s.aim "%" faint
    if count(s.test) > 0 and pct < s.aim
      "Behind by" s.aim - pct "points" color bad small
form subject, "Add subject"
form test, "Add test"

@create style=short domain=b2_gpa_calc
semester gpa with credits
---
app "GPA" school plum
table course name text, credits num 1..6 = 3, grade pick A|B|C|D|F = A
let points(g text) = if(g = A, 4, if(g = B, 3, if(g = C, 2, if(g = D, 1, 0))))
let gpa = sum(course, it.credits * points(it.grade)) / max(sum(course.credits), 1)
text fixed(gpa, 2) big
"Credits" sum(course.credits) faint
list course
form course
===
