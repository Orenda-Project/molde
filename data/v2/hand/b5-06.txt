@create style=detailed domain=b5_barber_chairs
barber shop with 3 chairs. each haircut has the barber, price and tip. barbers keep 40 percent, shop keeps the rest, 40 is a setting. show what each barber earned this week and the shop's share
---
app "Barber Shop" tool slate
table barber name text
table cut barber ref barber, price money, tip money = 0
setting barber_share num = 40 "Barber share %"
"Shop share this week" round(sum(cut.price week) * (100 - barber_share) / 100) big
each barber sort name as b
  row card tap edit b
    b.name bold grow
    count(b.cut week) "cuts" faint
    round(sum(b.cut.price week) * barber_share / 100 + sum(b.cut.tip week)) bold
form cut, "Add haircut"
form barber, "Add barber"
===

@create style=custom_ui domain=b5_bus_seats

---

table trip route text, day date
table ticket trip ref trip, seat num 1..40, passenger text

  stack card gap 1
    row
      t.route bold grow
      t.day faint
      count(t.ticket) "of 40" faint
    grid 8 gap 1
      each 1..40 as n
        if count(t.ticket where seat = n) > 0

            n tiny align center
