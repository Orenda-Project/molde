@create style=detailed domain=b2_nurse_shifts
I'm a staff nurse doing rotating shifts at three wards. I log each shift with the ward and whether it was day or night, hours worked. At month end I need the hours per ward and the number of night shifts.
---
app "Nurse shifts" heart plum
table ward name text
table shift ward ref ward, kind pick Day|Night = Day, hours num 1..16 = 8
"Hours this month" sum(shift.hours month) big
"Night shifts" count(shift month where kind = Night) faint
each ward sort name as w
  row card
    w.name bold grow
    sum(w.shift.hours month) "h" bold
    count(w.shift month where kind = Night) "nights" faint
form ward, "Add ward"
form shift, "Log shift"

@create style=custom_ui domain=b2_flashcard_leitner
flashcards in three boxes, new cards start in box 1, I tap right to move up and wrong to go back to box 1, show how many in each box
---
app "Leitner" brain ocean
table card front text, back text, box num 1..3 = 1
state flip bool = no
row gap 2
  each 1..3 as b
    stat count(card where box = b), join("Box ", b)
each card where box < 3 shuffle top 1 empty "Nothing left in boxes 1 and 2"
  stack card gap 2 tap set flip = not flip
    it.front big
    if flip
      it.back head color accent
      row gap 1
        button "Right" tap set it.box = it.box + 1 then set flip = no
        button "Wrong" tap set it.box = 1 then set flip = no
form card, "Add card"
