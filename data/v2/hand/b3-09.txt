@create style=detailed domain=b3_volleyball
Volleyball matches with a home and away team name. Each match has sets with the points each side scored. Show sets won by each side as the match result and list the set scores under each match.
---
app "Volleyball" ball ocean
table vmatch home text, away text
table vset vmatch ref vmatch, home_pts num 0..40, away_pts num 0..40
each vmatch sort at desc as m
  let home_sets = count(m.vset where home_pts > away_pts)
  let away_sets = count(m.vset where away_pts > home_pts)
  stack card gap 1
    row
      m.home bold grow
      home_sets "-" away_sets big
      m.away bold grow align end
    each m.vset as s
      "Set" index + 1 ":" s.home_pts "-" s.away_pts faint
form vmatch, "New match"
form vset, "Add set score"
===
