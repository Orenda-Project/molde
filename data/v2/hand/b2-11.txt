@create style=detailed domain=b2_mother_tabs
Mum's family board with two tabs: the first tab for the kids' chores today with ticks, the second tab for the doctor and school appointments with dates. Kids and appointments are linked by the kid's name.
---
app "Family board" home plum
table kid name text
table chore kid ref kid, what text
table done chore ref chore
table appointment kid ref kid, what text, day date
screen chores "Today" check
  each chore as c
    row card
      toggle c.done
      c.what grow
      c.kid.name faint
  form chore, "Add chore"
screen dates "Dates" calendar
  each appointment where day >= today sort day as a
    row card tap edit a
      a.day bold
      a.what grow
      a.kid.name faint
  form appointment, "Add appointment"
  form kid, "Add kid"
===

@create style=detailed domain=b2_physio_clinic
