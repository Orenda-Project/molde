@create style=detailed domain=b4_bee_hives
i keep 14 bee boxes on a farm. each box gets inspected every two weeks and i note if i saw the queen. honey i take out is weighed in kg per box. show which boxes are overdue for a look and total honey this year
---
app "Apiary" leaf mint
table hive name text, strength pick Weak|Medium|Strong = Medium
table inspection hive ref hive, queen_seen bool, note text?
table harvest hive ref hive, kg num 0.1..60
"Honey this year" sum(harvest.kg year) "kg" big
"Boxes to inspect" count(hive, due(it.inspection, 14)) head color warn
each hive sort name as h
  row card tap edit h
    stack grow
      h.name bold
      text h.strength "- last look" since(h.inspection) "days ago" faint
    text sum(h.harvest.kg) "kg"
    button "Inspected" tap add inspection hive = h
form harvest, "Weigh honey"
form hive, "Add box"
===
