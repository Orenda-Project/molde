@create style=detailed domain=b4_catering_events
we do catering for weddings and parties. each event has a date, number of guests, price per head and an advance. dishes for each event are listed with the quantity of rice kg or chicken kg. show upcoming events and the money still to get
---
app "Catering" food plum
table event name text, day date, guests num 10..2000, per_head money, advance money = 0
table dish_line event ref event, dish text, kg num 0.5..500
let total_due = sum(event where day >= today, it.guests * it.per_head - it.advance)
"To collect from upcoming" total_due big
each event where day >= today sort day as e
  stack card gap 1 tap edit e
    row
      e.name bold grow
      text e.day faint
    text e.guests "guests, total" e.guests * e.per_head
    text "kg of food" sum(e.dish_line.kg) faint
form event, "New event"
form dish_line, "Add dish"
