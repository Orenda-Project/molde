@create style=custom_ui domain=b5_star_gazing
stargazing nights log: date and place, and under each night the things I saw (planet, galaxy, comet etc) with a 1 to 5 rating. show each night as a card with a star row that fills by best rating
---
app "Night Sky" moon ink
table night day date, place text
table sighting night ref night, object text, rating num 1..5 = 3
each night sort day desc as n
  stack card gap 1 tap edit n
    row
      n.day bold
      n.place grow faint
    row gap 0
      each 1..5 as s
        icon star color if(s <= max(n.sighting.rating), warn, muted)
    each n.sighting as g
      g.object g.rating faint
form sighting, "Add sighting"
form night, "New night"
===
