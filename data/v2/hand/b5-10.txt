@create style=detailed domain=b5_tour_guide
I guide small tour groups in the old city. a group has a size and each tour has stops with minutes spent. show total walking time of the tour and how many minutes since 9 am the last stop ends if I start at 9:00
---
app "Tour Guide" map ocean
table tour name text, people num 1..50
table stop tour ref tour, place text, mins num 5..120 = 20
each tour sort name as t
  stack card gap 1
    row
      t.name head grow
      t.people "people" faint
    "Total time" sum(t.stop.mins) "min, ends at" join(9 + floor(sum(t.stop.mins) / 60), ":", fixed(sum(t.stop.mins) % 60, 0)) bold
    each t.stop as s
      row
        s.place grow
        s.mins "min" faint
form stop, "Add stop"
form tour, "New tour"
