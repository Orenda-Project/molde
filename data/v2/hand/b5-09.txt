@create style=custom_ui domain=b5_hospital_beds
small private hospital wards with a number of beds each. admissions list the patient and a discharged tick. draw each ward as a row of bed squares, filled for occupied beds, and say how many beds are free
---
app "Bed Board" bed ocean
table ward name text, beds num 1..40
table admission ward ref ward, patient text, discharged bool
each ward sort name as w
  let used = count(w.admission where discharged = no)
  stack card gap 1
    row
      w.name bold grow
      w.beds - used "free" bold color if(used >= w.beds, bad, good)
    grid 10 gap 1
      each 1..w.beds as n
        box height 14 radius 3 fill if(n <= used, accent, soft)
    each w.admission where discharged = no as a
      row
        a.patient grow
        toggle a.discharged
form admission, "Admit patient"
form ward, "Add ward"
===

@create style=detailed domain=b5_scrap_dealer
I buy scrap (iron, copper, paper, plastic) by the kg and sell to the big dealer. each material has a buy rate. I log kg bought and kg sold with the selling rate. profit per material and total
---
app "Kabari" box slate
table material name text, buy_rate money
table bought material ref material, kg num 0.5..2000
table sold material ref material, kg num 1..5000, rate money
let profit(m material) = sum(m.sold, it.kg * it.rate) - sum(m.bought.kg) * m.buy_rate
"Total profit" sum(material, profit(it)) big
each material sort name as m
  row card tap edit m
    stack grow gap 0
      m.name bold
      sum(m.bought.kg) - sum(m.sold.kg) "kg in godown" faint
    profit(m) bold color if(profit(m) < 0, bad, good)
form bought, "Bought scrap"
form sold, "Sold scrap"
form material, "Add material"
