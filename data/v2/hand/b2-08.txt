@create style=detailed domain=b2_math_olympiad
Math olympiad prep group: each student solves problems from topics (algebra, geometry, number theory, combinatorics). I log how many problems were solved on which topic and want a leaderboard plus each student's weakest topic.
---
app "Olympiad prep" brain plum
table student name text
table solved student ref student, topic pick Algebra|Geometry|Number_theory|Combinatorics = Algebra, count num 1..50
each student sort sum(it.solved.count) desc as s
  stack card gap 1
    row
      s.name bold grow
      sum(s.solved.count) "solved" big
    each options solved.topic as t
      row gap 1
        text t grow faint
        sum(s.solved.count where topic = t) small
form student, "Add student"
form solved, "Log problems"
