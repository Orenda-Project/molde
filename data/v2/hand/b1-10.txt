@create style=detailed domain=b1_cow_heat_calendar
for each cow I mark the days she came in heat, so I can guess the next one about 21 days later. show a calendar of heat days for the selected cow and the date of expected next heat
---
app "Heat Calendar" paw plum
table cow_h name text
table heat cow_h ref cow_h
state pick_cow text = ""
each cow_h sort name as c
  row card tap set pick_cow = c.name fill if(pick_cow = c.name, accent, surface)
    c.name bold grow
    if count(c.heat) > 0
      text "next about" last(c.heat.at) + 21 faint
    toggle c.heat
form cow_h, "Add cow"
===

@create style=detailed domain=b1_rent_raise
I rent flats and every year the rent goes up by a percent which is a setting. each flat has a starting rent and a start date; show the rent each flat should pay now after the yearly raises
---

  let years = floor((today - f.start) / 365)
  let now_rent = round(f.start_rent * pow(1 + raise / 100, years))

      f.name bold
      text years "raises so far" faint
    now_rent bold
