@create style=detailed domain=b1_driving_school
driving school: each learner buys a package of lessons for a fee. I tick each lesson taken and see lessons left in the package and how much fee is still pending
---
app "Driving School" car ocean
table learner name text, package num 5..40 = 12, fee money, vehicle pick Car|Bike = Car
table lesson learner ref learner
table feein learner ref learner, amount money
each learner sort name as l
  let taken = count(l.lesson)
  row card tap edit l
    stack grow
      l.name bold
      text l.vehicle faint
    text l.package - taken "lessons left"
    text "fee pending" l.fee - sum(l.feein.amount) color if(sum(l.feein.amount) < l.fee, warn, good)
    toggle l.lesson
form feein, "Fee received"
form learner, "New learner"
===

@create style=multi_feature domain=b1_welding_jobs
welding workshop: jobs for customers, each job has the material cost and labour days. I want profit on each job as price minus material minus labour at 1500 a day, plus the number of jobs still open
---

@create style=custom_ui domain=b1_greengrocer_waste
for each vegetable I note kg bought, kg sold and kg thrown away. show the waste percent in red when above 10 and a bar chart of waste per vegetable
---
app "Waste Watch" apple mint
table veggie name text
table stockin veggie ref veggie, kg num 1..1000
table stockout veggie ref veggie, kg num 0.5..1000, how pick Sold|Wasted = Sold
each veggie sort name as v
  let wasted = sum(v.stockout.kg where how = Wasted)
  let pct = wasted * 100 / max(sum(v.stockin.kg), 1)
  row card tap edit v
    v.name bold grow
    text round(pct) "% waste" color if(pct > 10, bad, ink)
bars veggie, sum(it.stockout.kg where how = Wasted), it.name
form stockin, "Bought"
form stockout, "Sold or thrown"
form veggie, "Add vegetable"
