@create style=custom_ui domain=h2b_cricket_scorer
street cricket scorer. buttons for 1 2 4 6 and wicket and a dot ball. shows runs/wickets and overs like 3.4. reset button
---
app "Scorer" ball ink
state runs num = 0
state wkts num = 0
state balls num = 0
join(runs, "/", wkts) huge align center
join(floor(balls / 6), ".", balls % 6) "overs" align center
row gap 1
  each [1, 2, 4, 6] as r
    button r tap set runs = runs + r then set balls = balls + 1
row gap 1
  button "Dot" tap set balls = balls + 1
  button "Wicket" tap set wkts = wkts + 1 then set balls = balls + 1
button "Reset" tap set runs = 0 then set wkts = 0 then set balls = 0
===

@create style=custom_ui domain=h2b_unit_convert
quick converter with one box for the number and chips to pick km to miles, kg to pounds or celsius to fahrenheit
---
app "Convert" calc slate
state v num = 0
state mode pick Km_to_miles|Kg_to_pounds|C_to_F = Km_to_miles
field v "Value"
choice mode
let out = if(mode = Km_to_miles, v * 0.621, if(mode = Kg_to_pounds, v * 2.205, v * 9 / 5 + 32))
stat fixed(out, 2), "result"
