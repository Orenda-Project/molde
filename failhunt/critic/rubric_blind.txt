BLIND RUBRIC (written before opening labels/gemma-r3-creates.txt)
2 = the program is the kind of app asked for AND every explicit specific in the request (named fields, units, ranges, charts, stats, labels, goal numbers) is present and works; nothing nonsensical.
1 = right kind of app, but one explicit specific is missing, garbled or wrong (wrong field, wrong formula, wrong label/number), or it contains an unexplained or absurd default that the request did not ask for.
0 = wrong kind of app, checker-broken or truncated, looping garbage, or text unrelated to the request.
Tie-break: if the program would clearly confuse a user about what the app does, that is 0 not 1.
Non-English requests: judge the program against the English meaning of the request.
